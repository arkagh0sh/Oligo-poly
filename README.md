# oligo-poly

A Rust library for polynomial rings under oligomorphic group actions.
Its goal is to implement the equivariant Buchberger algorithm of
A. Ghosh and A. Lopez, *Computability of equivariant Gröbner bases* (2025).

## Status

- Polynomial rings over a field, with variables of any ordered type, and
  Gröbner bases: Buchberger's algorithm, reduced Gröbner bases, ideal
  membership, inclusion, equality, sum and product
  (`src/mon.rs`, `src/ideal.rs`).
- A framework for equivariant algorithms over ordered oligomorphic structures,
  with the dense linear order (Q, <) and the universal dense meet-tree with a
  lexicographic order T_< as examples
  (`src/atoms.rs`, `src/elements_with_atoms.rs`, `src/dlo.rs`, `src/tree.rs`).
  It is only built with the Cargo feature `equivariant`.
- The equivariant Buchberger algorithm, in which a polynomial f is only
  reduced by elements h with supp(h) ⊆ supp(f) (`src/equivariant.rs`, example
  `equivariant_demo`). `equivariant_buchberger` computes a weak equivariant
  Gröbner basis, and `equivariant_groebner_basis` computes an equivariant
  Gröbner basis with the colouring of Section 5 of the article
  (`src/coloured.rs`). With the latter, f is in the ideal if and only if
  `reduces_to_zero` holds.

## Building and testing

```sh
cargo test
cargo test --features equivariant   # builds the crate rug, which compiles GMP
cargo run --release --features equivariant --example equivariant_demo
cargo run --release --features equivariant --example finite_comparison
```

The example `finite_comparison` compares, for growing finite sets S of atoms,
the ordinary Gröbner basis of the ideal generated by the instances of the
generators in the variables of S with the restriction to S of the equivariant
Gröbner basis, which is a Gröbner basis of I ∩ K[X_S]. It reports the times,
the sizes of the bases, and whether the two ideals are equal. Its options are
described at the top of `examples/finite_comparison.rs`.

The example `elimination_comparison` applies the colouring trick to ideals I
of K[x1, ..., xn] with the trivial group (`src/trivial.rs`). The result is a
basis whose elements in K[X_V] form a Gröbner basis of the elimination ideal
I ∩ K[X_V], for every set V of variables. It compares the trick with the
ordinary Gröbner basis, which has this property only for V = {x1, ..., xk},
and with the union of the reduced Gröbner bases of all 2^n elimination ideals
(`ideal::elimination_ideal`).

```sh
cargo run --release --features equivariant --example elimination_comparison -- --verbose --ideal "x2 + -1*x1; x1^2"
```

`one_colour_groebner_basis` is an experimental variant of the trick: every
coloured polynomial has at most one high variable, an S-polynomial is only
formed for pairs with consistent colours, and every new polynomial without a
high variable is added again with each one of its variables high. It is not
proved that its result is always an equivariant Gröbner basis. So far it was
correct on every example: 300 random ideals in 3, 4 and 5 variables
(`elimination_comparison --random 100 --vars N`), the built-in ideals, and
the ideals of `equivariant_demo` over (Q, <) and over trees. It is often much
faster than the full trick.

The example `elimination_scaling` compares the elimination method with the
one-colour trick (and optionally the other methods) on random ideals with more
variables. Each method runs on each ideal in a child process with a time
limit, and the property of every basis is checked against the elimination
bases.

```sh
cargo run --release --features equivariant --example elimination_scaling -- --vars 5,6,7 --count 10 --timeout 60
```

## Examples

### Gröbner bases

```sh
echo "x*y; x + y*z" | cargo run --example groebner_stdin -- f2
```

prints the reduced Gröbner basis {x², xy, x + yz} over the field with two
elements, for the lexicographic order in which a larger variable is more
significant. The script `scripts/compare_with_sympy.py` compares this example
with SymPy on random inputs.

### Where the naive equivariant Buchberger algorithm is not enough

Take the atoms of (Q, <) as variables, and let I be the equivariant ideal
generated by x_a x_b − x_c for all a < b < c. For a < b, the polynomial
x_b − x_a is in I: choose atoms c < d < a, then x_a ≡ x_c x_d ≡ x_b modulo I.
`equivariant_buchberger` stops with the minimal elements x_c − x_a x_b,
x_a² x_b − x_a x_b and x_a x_b² − x_a x_b (up to automorphisms). No element h
of this basis with supp(h) ⊆ {a, b} has a leading monomial that divides x_b,
so x_b − x_a does not reduce to zero. `equivariant_groebner_basis` returns the
basis {x_b − x_a, x_a² − x_a}, by which every element of I reduces to zero.

```rust
use atomic_hilbert::atoms::Orbit;
use atomic_hilbert::dlo::DLO;
use atomic_hilbert::equivariant::{equivariant_buchberger, equivariant_groebner_basis, minimal_basis, reduces_to_zero};
use atomic_hilbert::mon::Polynomial;
use num_rational::BigRational;
use rug::Rational;

type P = Polynomial<BigRational, DLO>;

fn x(i : i64) -> P {
    Polynomial::var(DLO::new(Rational::from(i)))
}

fn main() {
    // The equivariant ideal generated by x_a x_b - x_c for a < b < c.
    let generators = vec![Orbit::new(x(1) * x(2) - x(3))];
    let weak = equivariant_buchberger(generators.clone(), 100).ok().unwrap();
    let basis = equivariant_groebner_basis(generators, 100).ok().unwrap();
    // x_2 - x_1 is in the ideal, but it only reduces to zero by the second basis.
    assert!(!reduces_to_zero(&(x(2) - x(1)), &weak));
    assert!(reduces_to_zero(&(x(2) - x(1)), &basis));
    for g in minimal_basis(basis) {
        println!("{g}");
    }
}
```

The same happens for the ideal generated by x_a² − x_b for all a < b: the
polynomial x_a² − x_a is in it, because x_a ≡ x_c² for c < a and
x_c⁴ ≡ x_c², but it does not reduce to zero by the result of
`equivariant_buchberger`, whose elements with one atom are x_a⁴ − x_a² and
x_a⁶ − x_a⁴ (up to automorphisms). In both cases, the
derivation needs atoms below the atoms of the polynomial, which the support
condition forbids. The tests `membership_with_three_atoms` and
`new_orbits_are_added` in `src/equivariant.rs` check these two examples.

The atoms of the dense meet-tree T_< give an even simpler example. Let I be
generated by x_b − x_a for all a < b in the tree order. If a and b are
incomparable and m = a ∧ b, then x_b − x_a = (x_b − x_m) − (x_a − x_m) is in
I. The weak basis is the orbit of the generator alone, so x_b − x_a does not
reduce to zero by it, while `equivariant_groebner_basis` adds the orbit of
x_b − x_a for incomparable a and b (test `differences_along_the_tree_order`).

### Parallel Buchberger algorithms

`src/parallel.rs` has two parallel versions of Buchberger's algorithm, with the
same criteria and the same normal selection strategy as `ideal::buchberger`:

- `buchberger_batch`: in each round, all pending S-polynomials are reduced in
  parallel, and all non-zero remainders are added;
- `buchberger_first`: the pending S-polynomials are reduced in parallel in the
  order of the normal strategy, and only the first one that does not reduce to
  zero is added; the pairs whose S-polynomials reduced to zero are marked as
  done, and the other pairs stay pending. With one thread, this is the
  sequential algorithm.

The example `parallel_buchberger` compares them with the sequential algorithm
on the cyclic and Katsura systems and on random ideals:

```sh
cargo run --release --example parallel_buchberger -- --threads 1,2,4 katsura-4
```
